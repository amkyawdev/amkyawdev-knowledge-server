# Knowledge Server

အသိပညာဗဟုသုတ များစွာ ရရှိနိုင်ပါပါ

## အသုံးပါဋ္ဌာန်းနိုင်ပါပါ

### ပါဝင်းသုံးစွက်မှုများ

- 🔍 မြန်ဆန်သော ရှာဖွေမှု
- 📂 အမျိုးအစားခွဲခြားခြင်း
- 🛠️ JSON ပါဝင်းသုံးစွက်မှုများ
- 📱 မိုဘိုင်းပါဋ္ဌာနါက်ကပါ

### အမျိုးအစားများ

- **အထွေထွေ** - နှုတ်ဆက်ခြင်း၊ အကြောင်း၊ ဟာသများ
- **နည်းပညာ** - ပရိုဂရမ်းမင်း၊ API၊ Frameworks
- **Chatbot** - NLP၊ Dialog Management၊ Platforms
- **Coder** - Algorithms၊ Data Structures၊ Best Practices
- **Image** - ပုံများနှင့် သတင်းအများအပြား
- **Lifestyle** - ကျန်းမာခြင်း၊ ပညာရေး၊ အနုပညာ
- **Languages** - ဘာသာစကားများ

### အသုံးပါဋ္ဌာန်းနိုင်ပါပါ

```html
<script src="js/knowledge-loader.js"></script>
<script>
    const loader = new KnowledgeLoader();
    await loader.loadCategories();
    const categories = loader.getCategories();
</script>
```
